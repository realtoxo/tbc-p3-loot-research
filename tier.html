Measurement

Tier

At what point it makes sense to break an old set bonus: every subset of each spec’s bonus-carrying slots priced against its chase pieces, and the Tier 6 thresholds priced on the same baseline.

draft updated 2026-08-21

A tier piece is never priced alone: equipping it cuts an old set by one piece, and somewhere on that road an old bonus dies. This page answers the question the council actually faces, at what point does breaking the bonus pay. For every simulated spec, every subset of the entry set’s bonus-carrying slots was replaced with what the best-in-slot set wears there, on the otherwise unchanged entry set, so the tables below hold the best way to take one chase piece, two, three, and so on, and whether the old bonus survives each.

How to read every table

Every row is the spec’s entry set with only the named slots changed, the entry consumables, buffs and seed held still, so every figure is directly comparable with that spec’s entry figure on Simulated Throughput, and the empty row reproduces it. The plus or minus is one standard error, not a confidence interval.

A replaced slot keeps its enchant and a replacement arrives ungemmed. Which gems a chase piece takes is a separate question from what the piece is worth, so the figures understate a gemmed replacement, and a row with more replacements carries more empty sockets. The break-even readings therefore compare subsets of the same size: two subsets of equal size carry the same number of empty sockets, so the gap between the best that breaks a bonus and the best that keeps it is the bonus question and not the gems. The fully gemmed destination is priced by the anchor figures on the set pages, not here.

Each spec carries two rounds. The old-bonus round replaces subsets of the slots holding the entry set’s live bonuses with the spec’s chase pieces, the items its best-in-slot set wears there. The Tier 6 chase replaces subsets of the token slots with the tier anchor’s pieces, pricing the two-piece and four-piece thresholds and the order the tokens are best taken in. Nothing here is a ruling: the tables are measurements, and which claimant takes which token first is the council’s call.

The specs this page cannot measure

No simulator run backs this list. The three tanks are out of simulation scope by ruling, the Feral Cat’s rotation is not compiled into this build, and the healers have no captured gear set. What stands for them is the recorded council reading of the token arithmetic, quoted here and marked for what it is: a reading, not a measurement.

  • Feral Bear, unmeasured: structurally impossible to hold both bonuses (the council’s own reading of the token arithmetic).
  • Feral Cat, unmeasured: both tokens dead to the spec (the council’s own reading of the token arithmetic).
  • Protection Paladin, unmeasured: one token free, one a trade (the council’s own reading of the token arithmetic). Recorded ordering: route the gloves before the helm; the gloves are a pure gain.
  • Protection Warrior, unmeasured: depends on whether Archimonde is down (the council’s own reading of the token arithmetic).
  • Holy Paladin, unmeasured: works, though what it keeps is weak (the council’s own reading of the token arithmetic).
  • Priest Healer, unmeasured: the first token is free, and uniquely so for a structural reason: the set has a slot its bonus does not need (the council’s own reading of the token arithmetic).
  • Restoration Druid, unmeasured: the best line takes one token and refuses the other (a named source states it).
  • Restoration Shaman, unmeasured: the largest token downgrade found in the roster (the council’s own reading of the token arithmetic).
